- 根命令：`web:dev`、`web:build`、`web:verify`、`web:release`。
- 历史 FastAPI 启动脚本停用；Docker 旧服务需 `legacy` profile。
- Cloudflare/Pages 发布入口返回停用提示；正式发布只生成 Node 包。
- 验收结果：命令路径、历史服务和旧发布入口均已隔离；`web:verify` 全部通过。

## 第二步记录

- 后端新增 `site/worker/shared/api.mjs`，统一生成 JSON 成功/失败 envelope、`request_id` 和 `X-Request-ID`。
- 错误按 HTTP 状态映射到稳定 `code`；旧领域错误码保存在 `error.details.legacy_code`。
- 非 JSON 响应不转换，`.ics` 保持原始 `text/calendar`；静态资源和明确的 `text/*` 响应不包装。
- 前端新增统一 HTTP Client 和协议解析模块，集中处理 15 秒超时、`AbortSignal`、网络状态、401 会话失效和 `request_id`。
- 保留现有领域 API 导出路径；兼容旧直接成功响应和 `{ detail: { code, message } }` 错误格式。
- 邮箱 runtime 在 Worker 响应 envelope 下继续正确解包，未改变邮箱准入和邮件队列规则。
- 新增 `docs/API_CONTRACT.md`，记录领域路由、权限、字段、错误、幂等、并发、重试、缓存和敏感数据要求。
- 新增 API 契约测试，覆盖 401/403/404/409/422/429/503/500、request ID 一致性、旧新响应解析、异常日志脱敏及 `.ics` 非 JSON。
